## **Pravidla paprskové optiky**

1. přímočaré šíření světla
2. platí zákon odrazu a lomu
3. Princip záměnnosti chodu světelných paprsků
4. zanedbáme vlnovou délku ($$\lambda \doteq 0$$) vzhledem k rozměrům optické soustavy

**Optická soustava** - určité uspořádání zobrazovacích prvků a optických prostředí, které mění směr chodu paprsků

**Optické zobrazení** je postup, kterým získáme obraz předmětu

Svazek paprsků může být při vycházení ze soustavy

1. sbíhavý

## Zobrazení rovinným zrcadlem

- zobrazení odrazem = zrcadlo
  - zrcadla jsou předměty s lesklým povrchem (tenká vrstva kovu např. Ag, amalgám Sn)
  - dokonale rovná plocha = rovinné zrcadlo

# Zobrazovací rovnice zrcadla

<Frame caption="Výchozí obrázek pro odvození">
  ![Odvozenirovnice](/images/odvozenirovnice.png "Odvozenirovnice")
</Frame>

- $$a = \vert AV \vert$$ - předmětová vzdálenost
- $$a' = \vert A'V\vert$$ - obrazová vzdálenost
- $$f = \vert AF\vert$$ - ohnisková vzdálenost
- před zrcadlem: $$a,a',f,r > 0$$
- za zrcadlem: $$a,a',f,r < 0$$
- $$B,B'$$ nad $$A$$: $$y>0;y'>0$$
- $$B,B'$$ pod $$A$$: $$y<0,y'<0$$
- příčné zvětšení: $$Z = \frac{y'}{y} = - \frac{a'}{a} = -\frac{f}{a-f} = -\frac{a'-f}{f}$$, protože nějaký podobnosti a paraxiální prostor
- $$\vert Z \vert < 1$$ - zmenšený, $$\vert Z \vert = 1$$ - stejně velký, $$\vert Z \vert > 1$$ - zvětšený
- $$Z > 0$$ - přímý, $$Z < 0$$ - převrácený
- $$a' > 0$$ - skutečný, $$a' < 0$$ - zdánlivý

$$
\frac{a'}{a} = \frac{f}{a-f} \\ a'(a-f) = af \\ a'a - a'f = af \\ a'a = af + a'f \\ \frac{1}{f} = \boldsymbol{ \frac{1}{a} + \frac{1}{a'}}
$$

→ Platí i pro vypuklé zrcadlo

<Card title="Kdy je obraz stejně velký jako předmět" type="tip">
  - $$\vert Z \vert = 1$$
  - duté, hledáme vzdálenost $$x$$:
    - $$\frac{1}{x} + \frac{1}{x} = \frac{1}{f} \Rightarrow x = 2f = r$$, tedy předmět je na středu křivosti
  - vypuklé, hledáme vzdálenost $$x$$:
    - $$\frac{1}{x} + \frac{1}{-x} = \frac{1}{f} \Rightarrow \frac{1}{f} = 0$$, což nelze
