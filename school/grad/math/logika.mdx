# Výrok

Definice: Výrok je jakékoliv tvrzení, u kterého lze určit, zda je pravdivé či ne. 

## Pravdivostní hodnota

Neboli pravdivostní ohodnocení, říká, zda je výrok pravdivý či nepravdivý.

- "Karel IV. byl český král." - jedná se o pravdivý výrok, pravdivostní hodnota 1
- "Antonín Dvořák stále žije." - jedná se o nepravdivý výrok, pravdivostní hodnota 0
- "Dělej!" - nejedná se o výrok
