# Množiny

**Definice: Množina je souhrn objektů, který chápeme jako celek. Tyto objekty se nazývají "prvky množiny".**

Množiny se značí velkými písmeny (např. $$A$$), jejich prvky malými ($$a$$).

<u>Zápis množiny výčtem prvků</u>: $$A = \{a,b,c\}$$

Chceme-li zapsat, že prvek je v množině, použijeme symbol $$\in$$ (náleží). V opačném případě použijeme symbol $$\notin$$ (nenáleží).

<u>Speciální množiny</u>: 

- $$\mathbb{N}$$ - přirozená čísla $$\{1,2,3,4,...\}$$
- $$\mathbb{Z}$$ - celá čísla $$\{...,-2,-1,0,1,2,...\}$$
- $$\mathbb{Q}$$ - racionální čísla $$\{x = \frac{p}{q}; p \in \mathbb{Z} \land q \in \mathbb{N} \land \text{gcd}(p,q) = 1\}$$
- $$\mathbb{R}$$ - reálná čísla - racionální čísla a iracionální čísla
- atd.

<u>Zápis množiny pomocí vlastnosti</u>: $$A = \{x\in \mathbb{R}; x > 5\}$$

Pokud platí, že $$\forall x \in A \mathit{:x} \in B$$, pak říkáme, že $$A$$ je podmnožinou $$B$$. Značíme $$A \subseteq B$$. Tomuto vztahu se říká inkluze.

<u>Množinové operace</u>:

- Doplněk: Mějme dvě množiny $$A,B$$, kde $$B \subseteq A$$. Doplněk $$B$$ na $$A$$$$B'_A = \{x; x \in A \land x \notin B\}$$. Pokud je zřejmé, na jakou množinu doplněk je, stačí psát $$B'$$.
- Rozdíl: Mějme dvě množiny $$A,B$$. $$A \setminus B = \{x; x \in A \land x \notin B\}$$.
- Průnik: Mějme dvě množiny $$A,B$$. $$A \cap B = \{x; x \in A \land x \in B\}$$.
- Sjednocení: Mějme dvě množiny $$A,B$$. $$A \cup B = \{x; x \in A \lor x \in B\}$$.<br />
